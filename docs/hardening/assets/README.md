# Hardening Evidence

Folder ini digunakan untuk menyimpan bukti penerapan kontrol hardening pada
Target Node.

Setiap kontrol menggunakan ID yang sama dengan dokumen `hardening-plan.md`.

Format nama file:

- `H-XX-description-before.png`
- `H-XX-description-after.png`
- `H-XX-description-output.txt`

Bukti tidak boleh menampilkan password, private key, token, credential,
atau data sensitif lainnya.
